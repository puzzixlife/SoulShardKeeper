# 灵魂碎片管家 · SoulShardKeeper

适用于《魔兽世界：无限》（WoW Forever / 无限服）1.60.1，接口号 **16001**。

一个给术士用的轻量插件：把背包里的灵魂碎片控制在设定上限以内，并提供一个 **DaylightUI 风格**的术士灵魂球悬浮按钮。

> 界面材质与术士职业头像在运行时直接读取 **DaylightUI**，因此需要安装并启用 DaylightUI。本插件不包含、也不复制 DaylightUI 的任何美术资源；未安装 DaylightUI 时会回退到插件自带的紫色灵魂球和基础控件。

---

## 功能

- **超过上限自动清理**：背包内灵魂碎片总数高于「保留上限」时，在你正常按键或点击世界时，自动销毁多余的碎片，直到回到上限。
- **DaylightUI 风格悬浮球**：使用 DaylightUI 的术士职业头像作为球体，深色圆环与紫色辉光，中间实时显示背包内灵魂碎片总数。
- **左键销毁 1 个**：无论是否超过上限，左键点击悬浮球都会销毁 1 个灵魂碎片。
- **DaylightUI 风格设置窗口**：深色卡片、暖白文字、渐变顶线、DaylightUI 圆角/拨杆/滑条材质；右下角开关、顶部关闭按钮都按 DaylightUI 的视觉语言重做。
- **滑条整条可拖**：点击或按住滑条轨道任意位置即可调整，不必精确抓住小圆点。
- **右键打开设置**：调整上限、开关自动销毁、显示/隐藏、锁定位置、缩放、重置位置。
- **可拖动、可隐藏**：解锁后直接拖动悬浮球；隐藏后可用 `/ssk show` 恢复。
- **安全**：只销毁物品 ID `6265`（灵魂碎片）；战斗中暂停；光标上有物品时暂停；每次输入最多销毁 1 个；不会误删整组。
- **中英双语**：根据客户端语言自动切换。

## 安装

1. 关闭游戏。
2. 打开游戏目录下的：

   ```text
   World of Warcraft\_forever_\Interface\AddOns\
   ```

   如果没有 `Interface` 或 `AddOns` 文件夹，请手动新建。
3. 把压缩包里的 `SoulShardKeeper` 文件夹整个放进 `AddOns`，最终结构为：

   ```text
   _forever_\Interface\AddOns\SoulShardKeeper\SoulShardKeeper.toc
   _forever_\Interface\AddOns\SoulShardKeeper\Core.lua
   _forever_\Interface\AddOns\SoulShardKeeper\UI.lua
   _forever_\Interface\AddOns\SoulShardKeeper\Localization.lua
   _forever_\Interface\AddOns\SoulShardKeeper\Media\orb.tga
   _forever_\Interface\AddOns\SoulShardKeeper\Media\orb_glow.tga
   _forever_\Interface\AddOns\SoulShardKeeper\Media\slider.tga
   ```

4. 启动游戏，在角色选择界面的「插件」中勾选 **SoulShardKeeper / 灵魂碎片管家**。
5. 进入游戏后，术士角色会自动看到悬浮球。

如果插件显示为「过期」，勾选角色选择界面左下角的「加载过期插件」即可；当前版本接口号为 16001。

## 使用

- **左键**：销毁 1 个灵魂碎片。
- **右键**：打开设置。
- **拖动**：按住左键拖动（设置里未锁定位置时）。
- **隐藏**：设置里取消「显示悬浮球」，或输入 `/ssk hide`。
- **恢复**：输入 `/ssk show`，或点击插件列表里的 AddOns 图标。

### 设置项

| 设置 | 说明 |
| --- | --- |
| 启用自动销毁 | 关闭后只保留左键手动销毁 |
| 保留上限 | 0–100，默认 20；设为 0 会销毁所有灵魂碎片 |
| 每次销毁时在聊天框提示 | 默认关闭，避免刷屏 |
| 销毁时静音宝石音效 | 默认关闭，只静音销毁瞬间的拾取/放下音效 |
| 显示悬浮球 | 取消勾选即隐藏 |
| 锁定位置 | 防止误拖动 |
| 大小 | 70%–160% |
| 重置位置 | 回到屏幕中右侧 |
| 立即销毁 1 个 | 手动销毁一次（仍然遵守战斗中/光标限制） |

## 命令

```text
/ssk                打开设置
/ssk show           显示悬浮球
/ssk hide           隐藏悬浮球
/ssk lock           锁定位置
/ssk unlock         解锁位置
/ssk cap 10         保留最多 10 个灵魂碎片
/ssk on             开启自动销毁
/ssk off            关闭自动销毁
/ssk status         查看当前数量、上限和状态
/ssk reset          重置悬浮球位置和大小
```

## 自动销毁是怎么工作的（重要）

《魔兽世界：无限》沿用现代《魔兽世界》的插件安全规则：

> 插件每次「真实按键」或「鼠标点击」最多只能删除 1 件物品，不能在没有玩家输入的情况下后台静默删除。

所以本插件的做法是：

1. 检测背包里灵魂碎片的总数；
2. 如果超过上限，就进入「待清理」状态；
3. 你下一次按键、点击世界、点击悬浮球或点击「立即销毁 1 个」时，插件销毁 **1 个**；
4. 如果还超，就等你下一次输入再销毁 1 个，直到回到上限。

这不是插件偷懒，而是客户端限制。你不需要额外操作，正常打怪、跑路、按技能时它就会自己清理完。

- **战斗中不会销毁**，脱战后下一次输入继续。
- **光标上有物品时不会销毁**，避免把别的东西弄丢。
- **只销毁灵魂碎片**，不会碰其他物品。
- **堆叠的碎片**会先拆分出 1 个再销毁，不会一次删掉整组。

## DaylightUI 依赖

- 界面材质、术士职业头像、圆角/拨杆/滑条/渐变线均运行时读取：

  ```text
  Interface\AddOns\DaylightUI\Media\
  ```

  因此需要安装并启用 **DaylightUI**。
- 未安装 DaylightUI 时，插件会自动回退到自带的紫色灵魂球与基础控件，功能不受影响，但不再是 DaylightUI 外观。

## 常见问题

**Q：进游戏没看到悬浮球？**
A：确认角色是术士；确认插件已勾选；输入 `/ssk` 或 `/ssk show`。如果仍然没有，检查 `AddOns` 文件夹层级是否多套了一层。

**Q：数量超过上限了，但站着不动没反应？**
A：按一下任意键（移动、跳、技能都可以），或点击一下游戏世界。客户端要求有真实输入才允许删除。

**Q：为什么战斗中不删？**
A：现代客户端在战斗锁定期间限制物品操作。插件选择在战斗中暂停，避免报错或污染界面；脱战后会自动恢复。

**Q：会和别的灵魂碎片插件冲突吗？**
A：如果同时装了其他自动删除灵魂碎片的插件，可能一次输入删两个。请只保留一个。

**Q：更新客户端后插件过期？**
A：在角色选择界面勾选「加载过期插件」。如果接口号变化较大，可能需要更新插件。

**Q：想改颜色/大小/位置？**
A：设置里可以调大小和位置。想换回自带球体或改颜色，可替换 `Media/orb.tga`；DaylightUI 风格的头像和材质来自 DaylightUI，不在本插件内。
